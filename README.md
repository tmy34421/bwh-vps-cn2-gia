## 退款政策：最容易踩坑的一条

搬瓦工有 30 天退款保障，但这里的"30 天"指的是**账号注册后的 30 天**，不是你买 VPS 之后的天数。这是大量新用户踩过的坑：注册账号三个月后才买了台月付机器，以为刚买几天随时能退，实际已经过了退款窗口。

退款还需要同时满足几个条件，主要包括：账号信誉良好、无拒付记录、VPS 的 IP 未被屏蔽、**流量使用不超过月限额的 10%**、账号下 VPS 数量（含已取消）不超过 3 个。每个账号只有一次退款机会，用掉后永久失去资格。

另外两点要提前知道：

- 退款是退掉账号下**所有**服务，所有 VPS 立即停机，数据、快照、备份永久删除。申请前先备份数据。
- 支付宝付款的退款进入搬瓦工账户余额（Credit），只能用于再购买或续费，不能提现；PayPal 和信用卡则原路退回。

申请路径：登录后台 → Billing → Refunds，系统会判断是否符合条件，符合的话在生成的工单里回复确认即可，通常几十分钟到几小时内处理。

这个政策对新手其实是个可用的策略：注册账号后先买最便宜的月付或季付档位，在 30 天窗口期内把延迟、速度、稳定性都测一遍，不满意就全额退，账号还能继续用。👉 [注册后先选个低门槛套餐试线路](https://bit.ly/BandwaGon)
